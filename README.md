# Twinslop

Две вещи в одном репозитории:

1. **Twinslop Hands** — телефонный контроллер «два стика = две руки». Открывается
   в браузере телефона, работает как приложение (PWA), отдаёт положение рук по HTTP.
2. **`apk-report/`** — разбор APK из релиза `Ai` (`WVRClientv1release.1.apk`):
   что это за приложение, как устроен стрим, что за модификация внутри.
   Главный документ — [`apk-report/DEEP-REVIEW.md`](apk-report/DEEP-REVIEW.md).

---

## Twinslop Hands: два стика под телефон

### Запуск

```bash
node server.js          # без зависимостей, нужен Node 18+
```

Сервер напечатает адреса. Открой на телефоне `http://<ip-компьютера>:3000`
(телефон и компьютер — в одной Wi-Fi сети), поверни экран горизонтально.

- **Левый стик = левая рука**, **правый = правая**. `TRIG` и `GRIP` — кнопки
  указательного и среднего пальца для каждой руки.
- Значения `x, y` — от `-1` до `1`, где `y = 1` — вверх.
- В центре экрана — виртуальная плоскость с руками, видно, что уходит наружу.
- ⚙ — чувствительность, мёртвая зона, вибрация, инверсия по вертикали.
- ⛶ — полный экран + попытка зафиксировать ландшафт (Android/Chrome).

### APK (без интернета вообще)

Готовый APK лежит в релизе: **[Twinslop Hands APK](https://github.com/Belopus228/Twinslop/releases/tag/hands)**
(`TwinslopHands.apk`, ~0.4 МБ). Скачивается и ставится прямо с телефона
(Android разрешит «Установить из неизвестных источников»).

Внутри — тот же контроллер, но:

- веб-часть зашита в `assets/www`, приложение работает **полностью офлайн**;
- в `AndroidManifest.xml` **нет разрешения `INTERNET`** — то есть сетевых
  проверок и запросов в принципе быть не может, система их заблокирует;
- ландшафт зафиксирован, экран не гаснет, системные панели скрыты (immersive).

Собрать заново: `gh workflow run android-apk --ref arena/ac9c8af6-twinslop`
или локально `cd android && gradle assembleRelease` (нужны JDK 17 и Android SDK).

В браузере тот же интерфейс работает как PWA: добавь на домашний экран
(Chrome → «Установить приложение») — откроется без адресной строки.

### Что уходит на сервер

`POST /api/state` каждые 33 мс:

```json
{
  "L": { "x": 0.42, "y": -0.13, "trigger": 1, "grip": 0 },
  "R": { "x": -0.80, "y": 0.55, "trigger": 0, "grip": 1 },
  "sensitivity": 1.3,
  "deadzone": 0.06
}
```

Забрать оттуда:

| Метод | Что даёт |
|---|---|
| `GET /api/state` | последнее состояние + `age_ms` (сколько мс назад обновлялось) |
| `GET /api/stream` | SSE-поток изменений, подходит для реального времени |

```bash
node examples/read-hands.js http://localhost:3000   # печатает руки в консоль
```

Клавиатура для проверки без телефона: `WASD` — левая рука, стрелки — правая,
`Space` — хват, `Shift` — курок.

## Разбор APK

```
apk-report/
  DEEP-REVIEW.md    — главный отчёт: что за приложение, стек, стрим, модификация, риски
  SUMMARY.md        — паспорт: пакет, разрешения, движок, крупнейшие файлы
  deep/
    scripts.txt     — 3264 имени MonoScript (карта игровых систем)
    libs/           — строки нативных библиотек (стрим, микрофон, модкит)
    decrypt/        — крипто-проба: шифрование метаданных, упаковка модкита
```

Отчёт пересобирается автоматически — workflow `apk-inspect` скачивает APK,
разбирает его и коммитит результат:

```bash
gh workflow run apk-inspect --ref arena/ac9c8af6-twinslop
```
